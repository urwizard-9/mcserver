# LGMC 시험 대기실

별도 Paper 플러그인. LGMC 원본의 접속자 전원 참가 방식을 유지한다. `/ready`로 준비를 전환하고 `/lobby`에서 한국어 버튼을 누른다. 참가 신청/대기실 관전자 분리는 하지 않는다.

- 입장·게임 종료 후 기본 120초 안에 준비하지 않으면 강퇴(밴 아님).
- 준비한 사람은 제한 시간으로 강퇴하지 않는다. 준비를 취소해도 최초 마감 시간을 갱신하지 않는다. 마감이 이미 지났으면 다음 점검 때 강퇴될 수 있다.
- 30초·10초 구간에 미준비자에게 경고한다. 게임 중에는 준비 강퇴를 하지 않는다.
- 접속자 4~12명이 모두 준비하면 `lg start`를 한 번 호출한다.
- 원본 10초 카운트다운을 사용한다. 입장·이탈·준비 취소 시 취소하며 조건이 다시 충족되면 새 카운트다운을 시작한다.
- 서버 재시작/게임 종료 후 준비 초기화. 재시작 시 진행 중 게임 복구는 지원하지 않는다.
- 직접 `/lg start` 및 별칭 호출은 막고 준비 흐름을 사용한다.
- 대기 중 피해를 막고 공허 추락 시 대기 위치로 복귀. 게임 중 피해는 LGMC에 맡긴다.
- 입장 시 대기 중이면 안전 위치로 이동하고 Adventure 모드로 설정한다.

지원 조합: `LGMC 5.1.3-bedrock-trial.2`와 Paper 1.21.8. 다른 LGMC 버전이면 대기실 플러그인을 비활성화하고 오류를 기록한다.

설정은 `trial-data/plugins/LgmcLobby/config.yml`의 `ready-timeout-seconds` 및 `lobby` 좌표. 최소 제한 시간 30초. 변경 후 정상 재시작한다. 서버 콘솔의 `lobby` 명령은 인원·준비·시작·게임 상태를 출력한다.

빌드: `python3 scripts/build-trial-plugins.py`. 고정 Java 21 컨테이너를 사용하며 실행 중 플러그인은 변경하지 않는다. 결과는 `trial-data/lobby-build/`. 서버 정지 후 교체한다.

## 검증 구분

컴파일·서버 활성화·빈 서버 상태·직접 시작 차단을 우선 확인한다. 실제 두 계정으로 준비/취소, 모바일 메뉴, 120초 강퇴, 재접속을 확인해야 한다. 4인 이상에서는 정상 자동 시작·카운트다운 중 이탈/준비 취소·게임 종료 후 초기화를 확인한다. 코드 검사와 0인 서버 점검을 실기 통과로 기록하지 않는다.

## 한국어 메시지 (0.2.0-trial)

실행 폴더의 messages.yml에서 문구를 수정하고 정상 재시작한다. 중괄호 치환값은 보존한다. 누락 키는 내장 기본 문구를 사용한다. 콘솔 상태 출력과 감사 로그 필드는 번역하지 않는다.

사용자가 두 계정으로 새 맵·준비 메뉴·미준비 강퇴·4명 미만 시작 방지 작동을 확인했다. 새 메시지 파일 적용 후 화면 및 4인 실기는 별도 확인한다.

## 읽기 전용 미리보기 (0.3.0-trial)

관리자 `/lgpreview` 또는 `/lgpreview <정확한 접속 이름>`으로 표시한다. `lgmclobby.preview` 기본 권한은 op다. 휴대폰을 관리자 계정으로 만들지 않아도 PC 관리자가 `/lgpreview .Lumos7886`으로 열 수 있다. 2계정 모두 /ready 후 시험한다.

역할 카드=제목 견본, 투표·마녀=동작 없는 메뉴, 밤낮·승리=가짜 수치를 쓰는 본인 전용 안내다. 인벤토리를 수정하지 않고 클릭·드래그 이동을 막는다. 미준비 시간은 그대로이며 게임/카운트다운 중에는 사용할 수 없다. 원본 역할 데이터·실제 능력 처리는 호출하지 않는다.

클라이언트 시험: 메뉴 열기/닫기, 역할 제목, 두 메뉴의 설명, PC Shift클릭·숫자키·드래그 및 모바일 이동 조작에서 아이템이 옮겨지지 않는지, 종료 후 개인 인벤토리·준비 상태 유지 확인. 실제 4인 게임의 표시·메시지 대상·보조 손 정보 은닉은 별도 시험이다.
